# 🚖 Taxi Fare Analysis | Power BI Dashboard

## 📌 Project Overview

Taxi Fare Analysis is an interactive Power BI dashboard designed to analyze taxi booking data and understand business performance. The project explores booking trends, revenue, cancellations, vehicle types, and customer ratings through interactive visualizations.

## 🎯 Project Objectives

- Analyze total taxi bookings and booking status distribution.
- Understand ride cancellation patterns.
- Track monthly booking trends and revenue performance.
- Compare booking performance across vehicle types.
- Analyze customer and driver ratings.
- Present business metrics through an interactive dashboard.

## 🛠️ Tools & Technologies

- **Power BI Desktop** — Dashboard development and data visualization
- **Power Query** — Data cleaning and transformation
- **DAX** — Calculated measures and KPIs
- **CSV** — Dataset storage and input



## 📈 Key Analysis Areas

- **Booking Analysis:** Total bookings and booking status distribution.
- **Revenue Analysis:** Revenue performance and booking value trends.
- **Cancellation Analysis:** Cancelled rides and booking cancellation patterns.
- **Vehicle Analysis:** Comparison of booking performance by vehicle type.
- **Rating Analysis:** Customer and driver rating patterns.
- **Time-Based Analysis:** Monthly booking trends and date-range filtering.
